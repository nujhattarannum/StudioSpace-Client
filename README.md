## 🌟 Project Overview
StudioSpace is a dynamic, multi-role studio rental platform designed to connect creative professionals (photographers, podcasters, filmmakers) with studio hosts. It features secure authentication, real-time availability management, double-booking prevention, and an integrated owner dashboard for handling incoming reservation requests.

## 🛠️ Tech Stack
* **Front-End:** Next.js (App Router), React, TypeScript, Tailwind CSS, Shadcn/ui, Lucide Icons, React Toastify.
* **Back-End & Database:** Node.js, Express.js, MongoDB, MongoDB Native Driver / Mongoose.
* **Authentication:** Better-Auth (with secure HTTP-only cookie validation).
* **Deployment:** Vercel (Client-side) & Vercel/Render (Server-side).

## 🚀 Key Features
* **Multi-Role User Experience:** Seamless switching between creator mode (browsing and booking spaces) and host mode (managing listings and client requests).
* **Owner Dashboard:** A centralized hub where hosts can update space details, delete listings, and review incoming reservation requests with instant **Confirm** or **Reject** actions.
* **Advanced Booking System:** Integrated calendar date pickers and slot selection with automatic calculation of total rates and guest capacity tracking.
* **Robust Security & Protected Routes:** Protected client and host routes guarded by Better-Auth session validation.
* **Responsive & Dark Mode UI:** Fully custom-styled UI with tailored light and dark mode themes, built using Tailwind CSS and mobile-first layouts.
